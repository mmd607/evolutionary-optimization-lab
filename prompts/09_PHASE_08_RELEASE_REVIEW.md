# Phase 08 — Final Quality and Release Readiness Review

## Goal
Audit engineering, scientific validity, reproducibility, and documentation.

## Checklist
- Clean environment installation;
- all tests, lint, formatting, and type checks;
- algorithm invariants and budget accounting;
- dataset provenance and licenses;
- no leakage in HPO;
- complete run metadata and seeds;
- reproducible tables/figures;
- verified citations and manuscript claims;
- dashboard uses real artifacts;
- no secrets or large data in Git;
- README quick start and reproduction guide;
- known limitations and future work;
- citation metadata and license.

Do not publish, push, merge, or create a release without explicit user approval.
