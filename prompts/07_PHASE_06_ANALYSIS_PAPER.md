# Phase 06 — Statistical Analysis and Research Report

## Goal
Turn completed, verified experiment artifacts into reproducible analysis assets and an honest manuscript draft.

## Tasks
- Freeze final experiment artifacts and validate completeness.
- Aggregate per-run metrics without discarding failures.
- Compute mean/std, median/IQR, confidence intervals where justified.
- Apply appropriate statistical tests and multiple-comparison correction.
- Calculate effect sizes and explain practical meaning.
- Generate all tables and figures from code.
- Draft manuscript using `docs/paper_writing_guide.md`.
- Verify every citation and every numeric statement.
- Include limitations, threats to validity, and deviations.

## Acceptance
No placeholder result is presented as real; each table/figure can be regenerated; manuscript claims trace to artifacts and verified sources.
